**Fullstack-разработчик с упором на frontend.**

За это время выполнила **35+ коммерческих заказов** — от лендингов и многостраничных сайтов до задач по дизайну, разработке SPA и доработке готовых проектов.

Основные направления моего развития — **JavaScript, TypeScript, React, Vue.js и Node.js**.

Также имею коммерческий опыт создания дизайна лендингов и сайтов в **Figma**: разрабатываю структуру страниц, продумываю пользовательские сценарии и подготавливаю макеты для последующей реализации.

## Чем могу быть полезна

- **Верстка по Figma:** семантичные, адаптивные интерфейсы с вниманием к доступности, кроссбраузерности и деталям макета.
- **Интерактивность на JavaScript:** формы, модальные окна, слайдеры, аккордеоны, анимации и динамические элементы интерфейса.
- **Разработка frontend-приложений:** создание SPA на React и Vue.js, разработка компонентов, работа с состоянием и интеграция с REST API.
- **Разработка backend-части:** создание серверных приложений и REST API на Node.js и его фреймворках.
- **Полный цикл разработки сайта:** от структуры и дизайна до верстки, программирования, тестирования и публикации.
- **Полный цикл разработки веб-приложения:** frontend, backend, база данных, авторизация, интеграция API и деплой.
- **Разработка мобильных приложений:** создание интерфейсов и функциональности мобильных приложений с возможностью интеграции с серверной частью.
- **Работа над проектом целиком:** настройка сборки, подключение библиотек, оптимизация изображений и кода, публикация проекта.
- **Развитие существующих сайтов:** исправление верстки, доработка страниц и работа с уже написанным кодом.
- **Создание дизайна в Figma:** разработка макетов лендингов и сайтов с подготовкой к frontend-реализации.
